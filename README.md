# Agentic AI Memory: From Foundations to Reliable Systems

**Status:** Planning and research protocol (not yet a completed textbook).

An open, evidence-led textbook and hands-on learning journey about memory in AI agents: what it means, how it differs from context and state, the scientific ideas behind it, available technologies, architecture choices, experiments, and trustworthy evaluation.

## Who this is for

- **Students and newcomers:** intuitive explanations, small examples, visual learning paths, glossaries.
- **Software and AI engineers:** architecture trade-offs, runnable code, test cases, operational checklists.
- **Researchers:** primary-source citations, explicit assumptions, comparison methodology, reproducible experiments.

Each concept should be understandable before advanced terminology appears. Scientific rigor must not be replaced with marketing claims.

## Learning pathway

| Level | Questions we will answer |
| --- | --- |
| 1. Foundations | What is memory for an agent? How are memory, context, knowledge, state, and RAG different? |
| 2. Designs | What categories, lifecycles, storage and retrieval approaches exist? |
| 3. Build | How do tools and frameworks implement memory? How do we create and inspect real examples? |
| 4. Evaluate | How do we measure retention, correctness, safety, cost, and failure modes? |

See [the outline](docs/LEARNING_PATH.md), [project roadmap](ROADMAP.md), and [editorial standards](docs/EDITORIAL_STANDARDS.md).

## Planned outcomes

A free online book, versioned reference list, original and licensed diagrams, animations with accessible text alternatives, end-to-end open examples, reproducible tests, technology comparison tables, and a downloadable book when the publishing infrastructure is ready.

**Authoring principle:** distinguish verified evidence, engineering measurements, conceptual analogies, and proposals. Read primary papers in full where access and permissions allow; inspect official technical documentation and implementation details for product claims.

## Project process

The publication repository contains only material cleared for release. Internal research notes, agent instructions, strategy, and permitted full-text paper copies are managed in a separate private repository. This public repository has no hidden dependency on private data to build its published materials.

See [contribution guidance](CONTRIBUTING.md). References and technology coverage will be recorded with versions and review dates, not advertised as timeless.
