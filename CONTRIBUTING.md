# Contributing

Welcome contributions from students, researchers and engineers.

Begin with an issue describing the intended learning objective or fix. Small changes are preferred. For technical assertions cite primary papers or official versioned docs. Include reproducible test steps for code, and accessible text alternatives for visuals.

A submission should explain intended reader level, evidence, possible limitations, licensing status, and checks run. Never submit full-text third-party articles, confidential papers, API keys, personal data, or internal coordination notes.

Public PRs must pass publication checks and human review before merge. Copyright and license selection are pending; do not assume public content can be redistributed under any particular license yet. Use issues for errata with a link to the relevant chapter and source.

The project editor owns final editorial decisions. Disagreement is welcome when grounded in evidence.
